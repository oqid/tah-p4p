Do not present them as unfinished work or required next steps.** Each systolic phase is a separate steady case with constant prescribed diaphragm-inlet velocity selected from the sinusoidal motion equation. Any phase-specific CAD shapes remain stationary during their respective solves. “Quasi-steady” describes this collection of steady cases.

The USER CONFIRMED the diaphragm surface is an INLET, with velocity prescribed from sinusoidal displacement over 20 mm at the selected cycle position (peak approximately 12.6 cm/s). This is the actual method, not a moving wall. CAD swept-volume consistency is a recommended check, not an implemented prerequisite already satisfied. The notes also describe a parametrised dome/Boolean chamber geometry. Do not claim moving-mesh, transient or FSI simulations have been performed.

The proposed motion is x = S/2 [1 − cos(pi t/Ts)], v = pi S/(2 Ts) sin(pi t/Ts). For S = 20 mm, 120 BPM and 50% systole, Ts = 0.25 s and peak speed is 0.12566 m/s. Flow must follow −dV/dt; for a deforming dome, it is not generally area times this displacement speed. The preliminary notes report about 28 L/min instantaneous flow, which needs reconciliation with swept volume. Instantaneous flow is not cardiac output. Capacity is not net stroke volume. The planned 35 cc scaling rules are not yet confirmed. Uniform volume scaling would require length factor (35/50)^(1/3) = 0.887904.

Current entry point: `run_haem.py`; core: `haem5.py`; controlled-population analysis: `haem_diagnostics.py`; independent lysis screening: `haem5_empiricalthresholds.py`. CFD-Post exports contain positions, scalar stress, scalar speed and connectivity. Use plain Line exports for diagnostics. Scalar stress is molecular viscosity times scalar shear strain rate; explicit Reynolds stresses are excluded. Stress is sampled at segment endpoints. Duration is distance divided by average endpoint speed, with floor max(1% of positive path mean speed, 0.001 m/s).

Core power-law notation: HI[%] = A tau^alpha t^beta, alpha = stress exponent and beta = time exponent. GW: A = 3.62e−5, alpha = 2.416, beta = 0.785. HO: 1.80e−6, 1.991, 0.765. TZ: 1.228e−5, 1.9918, 0.6606. Taskin uses opposite alpha/beta symbol roles. HI2 sums beta A t_cumulative^(beta−1) tau^alpha dt. Primary HI3 is [sum(A^(1/beta) tau^(alpha/beta) dt)]^beta. The initial haem5 docstring misprints HI3; executed code is correct. Legacy `HI_percent` aliases refer to HI2.

Core averages use starting-speed proxy weights and all reconstructed paths. Diagnostics can accept actual flux weights and an outlet plane; absent those, completion is unverified. A line of equally spaced seeds does not establish equal-area sampling over a 3D inlet. Missing path counts do not quantify missing flow or recirculation. The runner's summary and diagnostics can use different populations; label them explicitly.

The code converts NIH[mg/100 L] = 1000 HI[%] (1−Hct) Hb, using Hct = 0.30 and Hb = 150 g/L. This reproduces stored values, conditional on the plasma-Hb/HI definition; do not call it measured NIH. SA = 10 sum(tau dt) in dyn·s/cm². Its 35-unit reference is not a clinical safety or activated-platelet threshold. Empirical screening compares longest contiguous exposures against manually traced RBC/platelet lysis curves; it does not model repeated exposures or sensitisation.
